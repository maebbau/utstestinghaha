# Collaborative GitHub Workflow

This repository demonstrates the five practical activities from Lecture 2:

1. Create a GitHub Actions workflow in `.github/workflows/main.yml`.
2. Detect the GitHub actor and append an update to `index.html`.
3. Append the actor, timestamp and source commit to this README.
4. Commit the generated changes back to the `main` branch with `github-actions[bot]`.
5. Publish and test `index.html` with GitHub Pages.

## Team files

- `leader.html` contains the team leader's feature.
- `member1.html` contains the team member's feature.
